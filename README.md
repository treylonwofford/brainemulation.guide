# BrainEmulation Hub

**[brainemulation.guide](https://brainemulation.guide)**

A simple hub for whole brain emulation and mind uploading research: what to read, who's working on it, and how to get involved.

Whole brain emulation is the attempt to scan a brain in enough detail to run a working copy of it on a computer. It's a small field with scattered resources and no single front door. This site is that front door, in the spirit of [aisafety.com](https://aisafety.com) and [digitalminds.guide](https://digitalminds.guide).

## What's on the site

- **Learn** – the best short and long introductions to the field
- **Communities** – organisations and forums that welcome newcomers
- **Events** – workshops, journal clubs and talks
- **Datasets** – public connectome data you can explore today
- **Newsletters** – how to stay up to date
- **Programs** – fellowships that accept brain emulation projects
- **Help out** – how to suggest corrections

## Contributing

The site is a single `index.html` file with no build step. To suggest a resource or fix a mistake:

- Open an [issue](../../issues), or
- Edit `index.html` and open a pull request

Good additions are things a newcomer would actually use: introductory reading, active communities, recurring events, public datasets, and programs that have accepted brain emulation work. Please include a link and one sentence on why it belongs.

## Running locally

Open `index.html` in a browser. That's it.

## Hosting

Deployed with Cloudflare Pages from this repository. Every commit to `main` redeploys the site.
